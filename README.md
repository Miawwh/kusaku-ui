# 💳 Kusaku UI — E-Wallet Mobile Prototype

A mobile-first interactive prototype for a digital wallet app. Features **18 interconnected pages** sliced from Figma with client-side JavaScript validation.

🎨 **Figma Design**: [View Figma File](https://www.figma.com/design/acomQC91mOUmQ88uke2ZzC/KUSAKU-TAILWIND?node-id=1203-1042&p=f)

---

## ✨ Features

- **18 Interconnected Pages**: Complete flow covering Auth, Dashboard, Top Up, Transfer, Withdrawal, Account, and Transaction Statuses.
- **Interactive Validation**: Real-time form formatting using Vanilla JS for a responsive prototype feel.
- **Tailwind CSS v3**: Clean utility-first styling with custom states (`peer`, `group-hover`).
- **Live Dev Server**: Hot-reloading setup with Browser-Sync & Concurrently.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6), Tailwind CSS v3
- **Tools**: Browser-Sync, Concurrently

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone [https://github.com/Miawwh/kusaku-ui.git](https://github.com/Miawwh/kusaku-ui.git)

# 2. Navigate to directory & install dependencies
cd kusaku-ui
npm install

# 3. Run development server (runs on http://localhost:3000)
npm run dev
